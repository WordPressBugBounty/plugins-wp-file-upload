	<p class="wfu-releasenotes-summary"><strong>Version 5.2.0</strong> is a security and maintenance update. It fixes an <strong>SQL injection</strong> issue reported through Patchstack &mdash; for this reason alone, updating as soon as possible is recommended. It also corrects a number of outdated links and descriptions throughout the plugin's documentation, and adds a short dismissible note in the upload settings about where files can be sent.<br /><br />
