	<p class="wfu-releasenotes-summary"><strong>Version 5.2.2</strong> is a security update. It fixes an issue where a file whose contents are HTML but whose type is detected as non-text (for example a video file carrying a hidden script) could be uploaded and then run as a script in the browser; such files are now rejected. It also fixes a critical error that could occur when deleting admin notifications in bulk or filtering them. Updating as soon as possible is recommended.</p>
